# Kestrel: review the design, not the code

2026-10-28. Task WA-925. Status: skeleton, waiting for William's review of the shape.

## Goal

William owns the design of every repo without reading code. He reviews four things, each made
from the code, so none can drift:

| Layer | Question it answers | Made by |
|---|---|---|
| imports | which file and package uses which | dependency-cruiser (API, not the bin) |
| api | what each package gives out, with signatures | ts-morph over source |
| schema | tables, columns, keys, indexes | tbls on a migrated Postgres |
| systems | repos, services and the seams between them | LikeC4 model (hand-written, seam-checked) |

The ICM cards stay. They hold what code cannot say: why this shape, trade-offs, extension points,
what a change hits. Kestrel checks that cards and generated files agree. Devboard shows copies to
annotate; it is never the source.

## The flow it serves

1. Discuss.
2. Design packet: this doc's shape, per change.
3. William annotates (Devboard copy).
4. Skeleton: real files, types, signatures, `todo()` bodies. It must typecheck.
5. `kestrel gen` on the skeleton. William reviews the generated pages. `kestrel approve` + commit.
6. Bodies.
7. `kestrel check` in the gate: drift from approved fails.
8. Ship.

Kestrel itself went through 1 to 5. Steps 3 and 5 are one pause here: William saw the tree in chat.

## File map

```
src/
  cli.ts            commands gen, check, approve, stamp; wires the rest
  config.ts         kestrel.json, zod schema, LayerId
  model.ts          Node, Edge, Graph; normalize, byGroup, merge
  diff.ts           approved vs current → Change[]; formatChanges
  store.ts          the files in git: current, approved, pages
  cards.ts          ICM frontmatter: coverage, entity, stale; stamp
  todo.ts           skeleton body helper; deleted when all bodies exist
  layers/
    layer.ts        interface Layer, LayerContext: the adapter seam
    index.ts        LAYERS registry
    imports.ts      adapter: dependency-cruiser
    api.ts          adapter: ts-morph
    schema.ts       adapter: tbls
    systems.ts      adapter: LikeC4; seams()
```

Who imports whom (generated from the skeleton, `todo.ts` left out):

```
cli    → config, cards, diff, store, layers/index
store  → model
diff   → model
cards  → model
layers/index → layer, imports, api, schema, systems, config
layer  → config, model
each adapter → layer
config → zod     cli → commander
```

Rule the gate will hold: `model` imports nothing of ours. Adapters import only `layer` (and
`model` types). Nothing imports `cli`.

## Patterns

- Adapter: each tool sits behind `Layer`. diff, store and cards know only `Graph`.
- One data shape (`Graph`): every later feature (site, packet, a new layer) works on all layers
  at once.
- Approval as a commit: `approved.json` changes only through `kestrel approve`. The commit's diff
  is the review record. No database, no server.
- Groups: a package, a table, a system. One file per group, so an approval and its diff stay
  small and per unit.

## Files in each repo that uses it

```
kestrel.json
map/generated/<layer>/<group>.current.json    every gen; the gate compares it
map/generated/<layer>/<group>.approved.json   kestrel approve only
map/generated/<layer>/<group>.md              Mermaid page to read
map/objects/...                               ICM cards; frontmatter adds covers + stamp
```

Card frontmatter, new keys:

```yaml
covers: ["imports:@wren/outreach", "schema:table:reach_posts"]
stamp: 3f9c1a2e   # hash of the covered approved nodes when a person last read the card
```

A card is stale when its covered nodes change and nobody restamps it. That replaces the hand
`verified: date @ commit` with a check.

## Trade-offs

- One shared Graph shape drops tool detail. Detail that matters goes in `attrs`, compared exactly
  (index columns and uniqueness, a signature's text).
- Signatures compared as text: a rename of a parameter shows as drift. Accepted: a public
  signature change should be seen.
- tbls needs a live, migrated Postgres. So the schema layer runs where one exists (wren CI's
  schema job, local docker), not in the lint gate.
- dependency-cruiser's bin refuses Node 25 (this Mac). Its API runs fine, and kestrel uses the
  API anyway.
- API Extractor dropped: it reads built `.d.ts`, and wren never emits. ts-morph reads source.
- File-level imports for 3,000 files is big. Stored per package, so git diffs stay per unit.
- LikeC4 over Structurizr: TypeScript, npm, static site; no Java or Docker.

## Extension points

- New layer: one file in `layers/`, one entry in `LAYERS` and `LAYER_IDS`, one config block.
  Next likely: Python imports (import-linter) for keycycle; Restate services from discovery.
- New check: a function over `Graph[]`, called from `check`. Example: a layer rule like
  "packages/core imports no channel-*".
- `site` (one index over all repos) and `packet` (a review page of what a skeleton changes): both
  read the store, both later.
